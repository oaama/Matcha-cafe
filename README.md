# Matcha Café Ordering System

**Developed by Eng. Angelo Rezq**

An Arabic-first, right-to-left ordering and café operations app. Customers browse the menu and place dine-in, takeaway, and delivery orders; staff use a protected dashboard to manage orders, shifts, expenses, inventory, and the menu.

## Tech Stack
Next.js, React, TypeScript, Tailwind CSS

## Features
- Customer-facing Arabic RTL menu and ordering (dine-in, takeaway, delivery)
- Staff dashboard: orders, shifts, expenses, inventory, menu management
- Role-protected admin area
